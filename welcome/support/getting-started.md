## 1. Environment Setup & Workspace Hygiene

* Install Visual Studio Code and TortoiseGit on your local machine to manage your site files offline.
* Clone your dedicated Git repository to create a complete, local mirror of your web ecosystem.
* Organize your root directory using clear folder hierarchies that reflect your top-level site sections.
* Establish local configuration files to route heavy media assets directly to your CDN subdomain.

---

## 2. Content Authoring & Folder Structuring

* Create new pages using standard Markdown, HTML, or PHP files directly within your node subfolders.
* Define page metadata—including SEO tags, titles, and dates—directly at the top of each content file.
* Group related articles, decks, or documents into sub-node folders to automatically build contextual menus.
* LeverageRevealJS slide decks or raw HTML templates whenever you need rich, interactive presentation pages.

---

## 3. Offline Review & Quality Assurance

* Preview your site structure locally on your machine before committing any updates to the server.
* Verify that file and folder names are formatted correctly to ensure clean, human-readable URLs.
* Conduct local team reviews to refine copy, check responsive layouts, and confirm link integrity.
* Document conversations or AI logs in your designated section to maintain transparent development records.

---

## 4. Version Control & Deployment

* Stage and commit your local changes using TortoiseGit with clear, descriptive commit messages.
* Push your updated commits to your public or private Git repository for version history tracking.
* Deploy the updated flat files to your server via a direct, secure FTP upload—no SQL sync required.
* Verify that your live site instantly reflects the new folder structure without clearing database caches.

---

## 5. Communication & Contact Management

* Set up structured email engagement templates instead of dynamic, database-driven contact forms.
* Test that contact buttons correctly trigger pre-filled email drafts in the visitor's default mail client.
* Maintain clean inbox filters to handle direct, user-initiated communications without captchas.
* Update your public "Who Is" directory whenever core team pledges or project goals evolve.

---

## 6. Long-Term Maintenance & Media Routing

* Offload heavy PDFs, high-res images, and video assets to your designated CDN folder to keep repositories light.
* Embed external audio or video media using lightweight, responsive HTML iframe containers.
* Map out a rolling three-year content outline to guide iterative updates and new section additions.
* Periodically pull server backups locally to ensure full data redundancy and complete digital sovereignty.
